# Workout Builder

A drag-and-drop workout builder built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## 🚀 Features

- Drag & Drop workout blocks
- Dynamic timeline scaling
- Automatic workout section generation
- Real-time distance calculation
- Responsive UI

## 🛠 Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- @hello-pangea/dnd

## ▶️ Run Locally

```bash
npm install
npm run dev
```

Open **http://localhost:3000**
